# Changelog

## [0.0.3] - Tools of the file, spindle limit of the server, resume and the job in two programs

- **The gate keeps to the spindle:** a spindle order carries the turns it asks for (the new setting `spindle_rpm`, 12000 by default, is what the spindle button asks), and the gate never lets it ask for more than the lower of `spindle_max_rpm` and the top speed of the spindle the machine carries, as the server says it. With the new setting `spindle_over = clip` (the default) an order for more is cut to that speed and the screen says so; with `refuse` it is refused with a reason. The confirmation of the spindle shows the turns it will really get, a move is never cut and a stop is never held back. A laser or a pick and place machine still has no spindle: its order is refused and its screen has neither the button nor the choice.
- **The tools of the file, and the spindle of the machine:** the job page reads the drilling or routing file that is chosen, shows its tools and how many holes or cuts each has, and a tap on a tool switches it off for the job (`skip_tools`); the page also shows the spindle the machine carries, as the server says it. This is the same code as EH3D-NODE-BUNGARD-HMI.
- **A stopped job goes on:** when a job leaves the machine the screen asks the server how it ended; a job that was cancelled or failed is shown as stopped with the holes (cuts) it did, and a button sends the same file again with `skip` set to those already done, so only the rest is drilled or routed. The tools switched off stay off and the start goes through the gate like any other.
- **Drilling and then routing:** a drilling file and a routing file chosen one after the other are two programs of one job: when the server says the drilling is done, the routing is made and waits for the operator to start it, and the job page names the program that comes next.
- **Texts:** the words for holes and cuts and five new ones (the order was cut to the top speed of the spindle, the refusal of an order beyond it, resume, stopped, next) in the 37 languages, and the fonts built again for the characters they need.
- **Tests:** the host tests of the sibling screen for the spindle limit, the tools, the report of a job, `skip`, resume and the chain of the two programs. The firmware has not been rebuilt with this change.

## [0.0.2] - Languages, quality and notices of the screen

- **Thirty-seven languages on the screen:** besides English, Spanish, Italian, German, French, European Portuguese, Chinese and Japanese, the texts of the screens (the tabs, the buttons, the refusals of the gate and, on a CNC machine, the whole quality check and every finding of the analyser) are written in Bulgarian, Croatian, Czech, Danish, Dutch, Estonian, Finnish, Greek, Hungarian, Irish, Latvian, Lithuanian, Maltese, Polish, Romanian, Slovak, Slovenian, Swedish, Norwegian, Icelandic, Ukrainian, Russian, Serbian (Cyrillic), Albanian, Catalan, Galician, Basque, and the two variants Brazilian Portuguese and Canadian French (which hold only what changes). One file each in `locales/` (`Key<TAB>text`), compiled into `core/locales_gen.hpp` by `tools/make_locales.py`; a text a language lacks is shown in English (in European Portuguese / French of France for the variants), and the setting `language` (and the notices `voice:LANG:f|m`) accept all the codes. The spoken alerts and orders stay in the first eight languages. The sentence "this kind of machine has no spindle" is not yet translated into the 29 (it is shown in English there).
- **Fonts for them:** `tools/make_fonts.py` builds `main/fonts/eh3d_font_16.c` and `eh3d_font_24.c` with only the characters the screen can draw (Latin and Latin Extended and Cyrillic from Montserrat, Greek from DejaVu Sans, Chinese and Japanese from Source Han Sans) and writes `core/font_ranges.hpp`; the symbols of LVGL stay in the built-in Montserrat as the fallback. They are compiled into the firmware and set as the font of the screen; this has not been built into a firmware nor seen on the real screen.
- **A selector of language in the settings:** a list that scrolls with the 37 names, each in its own language, and the one in use outlined.
- **Quality check and spoken notices, on a CNC machine only:** the sixth page of the screen (the verdict of the check of the work through the camera of the drill head, what was found, the ring of LEDs, the profile and the calibration, all through EH3D-SERVER) and the notices `sound_check_ok` and `sound_check_bad` (a beep or a recorded voice that says that the visual check of the board is correct or is not correct) come with `machine_kind = cnc`, the default. A laser or a pick and place machine has neither the page nor those two notices (`controls_for(...).quality_check`); the notices of the end of a job and of a tool change are played on every kind of machine. The recordings are read from `voices/LANG/f|m/<name>.wav` on the card (16 bits, mono) and the beep plays when one is not there.
- **Tests:** `test_locales` (every key has a text in every language, nothing is empty or too long for the screen, the name `hmi.cfg` and the dots stay, the script of each language is the right one, and every character of every text, of the names of the languages and of the keyboards is in the range of the generated fonts), `test_quality` (911 checks) and `test_notices` with the new notices; `test_machine` now also covers which kinds of machine have the quality check. The seven programs make 79053 checks; `python -I tools/make_locales.py --check` runs in the CI.
- **Built and run:** the rules and the texts are tested on a computer; the firmware has not been built with these changes, flashed to a module nor seen on the real screen.

## [0.0.1] - A touch screen for CNC machines, lasers and pick and place machines, on the hardware of the Bungard screen

- **The same screen for three kinds of machine:** the firmware and the rules of EH3D-NODE-BUNGARD-HMI (the 10.1-inch ESP32-P4 touch screen, the settings file, the gate with the confirmation and the hardware-stop latch, the spoken alerts and orders, the keyboards, the server link and the screens in eight languages) as a general purpose controller; a copy of that base that goes its own way from here.
- **The kind of machine:** `machine_kind` in the settings file (`cnc`, `laser` or `pnp`, `cnc` by default; a wrong value is reported and the default stays) decides what the screen may order. Only a CNC machine gets the spindle button; the gate refuses a spindle order on a laser or a pick and place machine whatever the other settings say, with a sentence in each of the eight languages.
- **Tests:** a fifth host test program for the kinds of machine (52 checks); the five programs make 1018 checks.
- **Built and run:** the rules are tested on a computer; the firmware has not been flashed to a module and nothing has been connected to a machine.
